## **Overview**
This pipeline provides an integrated approach for the analysis of 10x Genomics Multiome data, encompassing RNA and ATAC sequencing. It consists of three main R Markdown scripts:

**RNA_integration.Rmd**: Processes and integrates RNA sequencing data from multiple samples.
**ATAC_integration.Rmd**: Processes and integrates ATAC sequencing data from multiple samples.
**10XMultiome.Rmd**: Merges the RNA and ATAC data, conducting a joint analysis to explore gene expression and chromatin accessibility simultaneously.
